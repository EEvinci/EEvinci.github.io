# Fonts

Cormorant Garamond and LXGW WenKai TC subsets are reused from Evinci's approved personal visual identity. Both use the SIL Open Font License 1.1: https://openfontlicense.org/open-font-license-official-text/

- Cormorant Garamond: https://github.com/CatharsisFonts/Cormorant
- LXGW WenKai TC: https://github.com/lxgw/LxgwWenkaiTC

Original font names are retained in the embedded metadata. No font design modifications are made.
